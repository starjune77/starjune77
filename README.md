### 🚀 Projects

**🎮 [Recolor the Heart](https://github.com/Waldron-Wang/Roygbiv_GameJam)** · C#, Unity 2D · Respawn Game Jam 2026
Unity 2D action platformer about bringing 7 colors back to a gray city. I built the final Violet boss (10 attacks, 16 combat states), the level baking Editor tool, the shared slow motion time controller, and the tutorial and HUD UI.
[▶ Play on itch.io](https://patriotzest.itch.io/recolor-the-heart)

**📚 [MorrowLab](https://github.com/Ericsung20/MorrowLab)** · React, TypeScript, MediaPipe, Dexie/IndexedDB · Badger BuildFest 2026
Privacy focused study planner that tracks focus sessions and recommends the next day's schedule. Phone use and absence detection runs fully on device with MediaPipe and EfficientDet-Lite2. Featured in UW Tech Exploration Lab's first Insight Brief.

**👁️ Object Detection Model** · Python, PyTorch, YOLOv8, OpenCV, ONNX · The Academies by Harvard Student Agencies
Fine-tuned YOLOv8 on a custom 8 class dataset and sped up CPU webcam inference by exporting to ONNX.

**🤖 FIRST Robotics Team 45 (TechnoKats)** · Java, CAD
Software and mechanical member. Our robot ranked 10th of 75 in the 2025 FIRST Championship Johnson Division.
